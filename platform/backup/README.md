# 备份恢复规划

状态：规划。定义每项服务的数据、RPO/RTO、备份保留时间、加密密钥和集群外保存位置。

- Git：配置仓库与 GitLab 数据都保留集群外副本。
- GitLab：按官方流程处理数据库、仓库、对象存储与 secrets 的一致性和版本兼容。
- Elasticsearch：使用应用支持的快照恢复流程。
- PVC：区分文件备份、CSI snapshot 和应用一致性备份，不能只备份 Kubernetes YAML。

验收必须包括从空环境恢复及内容校验。Retain、同一磁盘上的副本和单纯 Pod 重启
都不能替代外部备份；删除 kind 集群之前应明确数据将受到什么影响。
